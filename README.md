# Genomic Expression Analysis & Advanced R Visualization

## Project Overview
This repository contains an advanced R data analysis and visualization pipeline developed for **BIO 579 (Data Analysis and Visualization in R)**. The script implements robust data wrangling techniques and generates publication-grade visualizations for high-throughput transcriptomic datasets.

## Key Technical Implementation
- **Data Wrangling & Transformation:** Leveraged `tidyverse` (`dplyr`, `tidyr`) to clean, filter, and compute statistical summaries across multi-condition experimental groups.
- **Statistical Processing:** Handled distribution transformations, p-value adjustments, and differential expression categorization.
- **Publication-Grade Graphics:** Engineered customized, high-contrast plots using `ggplot2` featuring tailored color palettes, annotation layers, and theme adjustments.

## Tech Stack
- **Language:** R
- **Core Packages:** Tidyverse, ggplot2, Viridis
- **Environment:** RStudio / R Markdown

## Repository File Structure
- `genomic_data_visualization.R` — Complete R script containing tidy data manipulation routines and ggplot2 visualization functions.
